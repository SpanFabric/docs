# North Star
**Local:** Windows, application/game, launcher, CPU, RAM, storage, input, networking, existing local GPU.  
**Remote:** physical GPU execution, VRAM, supported ray tracing and GPU compute.

The application must not know that its selected GPU is remote. All DX9/10/11/12, Vulkan and OpenGL ambitions stay in scope even when implementation is deferred. WAN, remote VRAM, local-GPU coexistence, vendor-neutral boundaries, open/replaceable critical dependencies and legitimate trust/signing are architecture requirements, not later product polish.

“Later” means deferred implementation, never deletion from scope.
