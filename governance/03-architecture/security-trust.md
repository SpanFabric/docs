# Security / Trust
Threat boundaries: untrusted network; potentially compromised peer; malformed graphics command/resource data; privilege boundary into KMD/vendor driver; cache/session isolation.

Baseline: mutual authentication, authenticated encryption, bounded parsers, replay/session-epoch protection, least privilege, quotas, fuzzing and no secrets in evidence. Production direction: signed WDDM driver, Secure Boot compatibility, optional TPM/host attestation.

Anti-cheat trust is external. The project exposes its real virtual-adapter identity and pursues official cooperation; it never hides or bypasses third-party controls.
