# Requirement Priorities
- **MUST**: architectural/correctness/safety/control-plane requirement; violation blocks affected acceptance.
- **SHOULD**: expected for the stated horizon; deferral requires explicit rationale and does not silently redefine the North Star.
- **MAY**: optional enhancement; cannot be used as prerequisite for a MUST unless promoted through governance.

Horizons distinguish `v0/proof`, `v1`, `v1.x`, and `later`. `later` is deferred implementation, not deleted scope.
